## PV_Dictionary v0.4.7 — 學生體驗與版面：列印、深色主題、鍵盤、字級

這一版是「用起來舒服」的一版，另外補上使用者指定的一件事：**使用說明要包含所有新功能**（見第 5 點）。

### 1. B-5 列印生字表（可選要印什麼）

單元標題列的 🖨 旁邊多了兩個勾選：

- **中文解釋**：不勾就不印中文（讓學生看英文解釋自己回想）
- **例句**：不勾就不印例句

勾選會記在這台裝置上；列印一律用淺色（深色主題印出來會是整片黑）。

### 2. F-3 顏色主題（跟隨系統／淺色／深色）

標題列多了 🖥／☀️／🌙 三段切換：

- **跟隨系統**（預設）：不覆蓋裝置設定，交給 CSS 的 `prefers-color-scheme`
- **淺色／深色**：明確選擇，記在 localStorage，重新載入後還在

深色票有兩個地方（跟隨系統那段、明確選擇那段），**`tests/guards.test.js` 會逐條比對兩段的變數與值** ——
所以不可能出現「選深色跟系統深色長得不一樣」這種只有一邊被改到的情況。

### 3. F-4 鍵盤操作與無障礙

- **`/`** 或 **Ctrl/⌘+K** → 跳到搜尋框（在輸入框裡打字時不會被搶走）
- **Esc** → 關掉最上層的東西（錄音視窗／登入／密碼／使用說明／管理區）
- **跳到主要內容**的連結（用 Tab 進來才出現）、`:focus-visible` 的重點外框、切換鈕都有 `aria-pressed`

### 4. F-5 字級

**A−／A／A+** 三段，改的是根字級（版面全部用相對單位，所以整體一起縮放）；選擇會記住。
瀏覽器驗收會確認 **A+ 之後版面不會橫向溢出**。

### 5. 使用說明包含所有新功能（使用者指定）

- 說明頁補上 v0.4.6 的新功能：**從 Excel／CSV 匯入**、**▶ 播放全部與 👩‍🏫／🤖 徽章**、
  **批次核准／退回與退回原因**、**單元 ⧉ 複製與 ↑↓ 排序**、**書本排序**；
  以及這一版的**主題與字級**、**列印選項**、**鍵盤快捷鍵**。
- **改了守門規則，讓「新功能必須寫說明」變成自動的**：說明頁每一節多一個 `covers`（這一節在講哪幾個介面入口），
  `tests/guide.test.js` 會拿 **`index.html` 裡每一個管理分頁按鈕的 id** 去對 ——
  以後管理區新增一個分頁卻沒寫進說明，測試會直接紅燈。
  另外也檢查播放／列印／主題／字級／搜尋等主要入口都有人說明。

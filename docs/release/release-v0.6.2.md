## Gary-Dictionary v0.6.2 — 版面修正（你回報的兩件事）

這一版只做兩件你回報的事，但兩件都查到「真正的原因」，不是調數字而已。

### 1. 字級三段「根本沒有改變」→ 幅度加大

- 原因：A− 是 15px、A 是 16px —— **只差 1px**（6%），A+ 也只有 18.5px（+15%）→ 按下去幾乎看不出來。
- 修法：改成 **A− 14px（−12.5%）／A 16px／A+ 19px（+18.75%）**。
- 實測（標題的實際大小）：**28px → 32px → 38px**（寬度 195 → 223 → 263px）。
- 守門：真瀏覽器檢查加了門檻 —— A− 必須**至少小 10%**、A+ 必須**至少大 15%**，
  以後再有人把差距調小會直接紅燈。

### 2. 帳號管理「操作」欄錯位 → 找到真原因

- 症狀（你的截圖）：帳號表格裡，網頁管理員那一列的高度與別人不同、「操作」欄的按鈕看起來跑掉。
- 真正原因：`.cell-actions` 這個 class **套在 `<td>` 上又是 `display: flex`** ——
  把表格儲存格變成 flex 容器之後，欄寬計算與垂直對齊都會壞掉。
  實測：同一格裡的 6 顆按鈕**各自落在不同的 y 座標（疊成 4 行）**，那一列被撐到 **156px**，
  別的列只有 60px → 看起來就是錯位，而且超出列高的按鈕會被裁掉（所以只看得到第一顆）。
- 修法：
  1. `<td>` 保持表格儲存格，flex 放在**裡面的一層** `.actions-row`。
  2. **特異度**：`.data-table td`（0-1-1）比 `.cell-actions`（0-1-0）高 ——
     一定要寫 `.data-table td.cell-actions`（0-2-1）才蓋得掉（第一版就是被蓋掉，才修不動）。
  3. 操作欄靠右對齊、按鈕不換行；**沒有操作可按的那一列（你自己）顯示「—」**，欄位看起來才完整。
- 實測：所有列高都是 **60px**、每列的按鈕都在**同一行**（distinct tops = 1）。

### 3. 順手修：授權清單的年級一直是空的

授權管理清單的範圍顯示讀的是 `grant.book_name`，但後端從 v0.5.0 起就只回 `grade`（書名已移除）
→ 前端一直顯示「· Unit 1」而書名那一段是空的。已改成讀 `grade`，並加檢查（有授權資料時要看到年級）。

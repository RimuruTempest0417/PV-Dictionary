## Gary-Dictionary v0.6.4 — 修回空間利用率，字級鈕的階梯也看得出來了

這一版處理你回報的兩件事：**「你根本沒有改到」** 與 **「令空間利用率降低了」**。

### 1. 空間利用率變差 —— 是我上一版改錯方向（已修回）

- v0.6.3 我把「內容欄寬」也從固定 px 改成 rem（`1080px → 67.5rem`）。
- 結果：按 A− 時，**整個內容區跟著變窄**（字變小、可用寬度也變小＝一頁看到的東西更少），
  按 A+ 又變寬 → 版面一直在跳，空間利用率在 A− 時掉最多。這不是你想要的。
- 已改回 **固定 1080px**：字級切換只改「介面元件的大小」，**不改版面可用寬度**。
- 實測（用你的視窗尺寸 1512×949）：

| | A− | A | A+ |
|---|---|---|---|
| 內容欄寬（.page） | **1080px** | **1080px** | **1080px** |
| 面板寬（佔視窗） | 1052px（69.6%） | 1048px（69.3%） | 1042px（68.9%） |

→ 三種字級都一樣，空間利用率不再變差（跟你原本習慣的版面相同）。

### 2. 「你根本沒有改到」→ 字級鈕的三個標籤

- 真正的原因有兩個：
  1. **減號被抬高**：字體把「−」（數學減號 U+2212）畫在數學軸上，所以「A−」看起來比「A」還高 →
     你看到的「A+ 最大、然後 A−、最後 A」就是這個錯覺。（你之前指定的「A− 要比 A 小」因此一直看不出來。）
  2. 三顆鈕的字級階梯不夠明顯。
- 修法：`A−` 改用 **ASCII 連字號（A-）**（位置跟 A 的字腰對齊），階梯改成
  **0.7rem < 0.85rem < 1.05rem**。
- 實測三顆鈕的實際字級：**9.8px ／ 11.9px ／ 14.7px**（A− < A < A+，光看按鈕就知道差別）。

### 3. 保留 v0.6.3 做對的部分

介面元件（切換鈕、頂欄、表格列高／字級、卡片）**仍然跟著字級縮放**（實測切換鈕 98×37 → 110×42 → 128×48）。

### 守門（真瀏覽器，之後改壞會紅燈）

- **內容欄寬必須不隨字級改變**（三種字級差 ≤ 3px）——就是這次回報的「空間利用率」。
- 介面元件尺寸**必須**跟著縮放（A+ ≥ 1.1×A、A− ≤ 0.92×A）：切換鈕、頂欄高度、帳號表格列高與字級。
- 三顆鈕的字級必須有階梯（A− < A < A+）。
- 三種字級都不能出現橫向捲軸。

## Gary-Dictionary v0.6.5 — 字級只留「A」與「A+」，縮小的 A− 已移除

你指定的做法：**把「改小」那個功能整個刪掉**，只保留 A（正常）與 A+（放大）。這一版就是這件事，
另外補上一個以前漏掉的守門（就是它漏掉，A− 的卡片才會看起來「寬而扁」卻沒被發現）。

### 1. 字級切換現在只有兩顆鈕：**A**（正常）／**A+**（放大）

| | A | A+ |
|---|---|---|
| 根字級 | 16px（預設） | 19px（+18.75%） |
| 標籤自身的字級 | 0.85rem | 1.05rem |

- 為什麼是拿掉而不是繼續修：A− 之所以「整體頁面大小看起來不正常」，是因為**年級卡片的寬度跟不上字級**。
  書架用 `repeat(auto-fill, minmax(10rem, 1fr))`，字級只影響「欄寬下限」，欄寬由固定的 1080px 內容欄撐滿 ——
  14px 與 16px 都湊到 6 欄，所以 A− 的卡片反而比 A 略寬（163.66 vs 161.33），只有高度縮小 → 看起來「寬而扁」。
  要修到滿意的比例，就得犧牲你指定的「固定內容欄寬（空間利用率）」；既然 14px 這一階沒有實際用途，直接移除最乾淨。
- **舊設定不會卡住**：以前按過 A− 的裝置（本機記著 `pv-font = 's'`）會自動回到 A（`FONT_VALUES` 已不含 `'s'`），
  CSS 也沒有 `:root[data-font="s"]` 這條規則了（真瀏覽器檢查有驗這一項）。

### 2. 補上漏掉的守門（v0.6.5 新增）

- 以前的字級檢查只量「標題字、字級切換鈕、內容欄寬、頂欄高度」，**從來沒有量過年級卡**（`shelf-card`）。
- 現在兩支真瀏覽器檢查都會量 **年級卡的寬與高**，門檻「A+ ≥ 1.10×A」：
  `tests/browser/demo-check.js`（本機 116 項）與 `tests/browser/live-check.js`（正式站訪客視角）。
- 也新增「字級只能有兩顆鈕（A／A+）」「已移除的 A− 不會殘留成第三種字級」兩項。

### 3. 沒有變的部分（v0.6.4 的定案全部保留）

- **內容欄固定 1080px**：字級只改介面元件大小，**不改版面可用寬度**（空間利用率不變）。
- 介面元件（切換鈕、頂欄、卡片、表格列高、間距）仍然跟著字級一起放大。
- 站內使用說明（❓→ 主題與字級）已同步改成「A／A+」，中英都更新。

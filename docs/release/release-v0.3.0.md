## PV_Dictionary v0.3.0 — 連上 Supabase ＋ 密碼自助 ＋ 三個介面修正

使用者這一批要求（逐字）：

> 「可以接着做連上網，然後請允許自己修改自己的密碼，現在修改自己的密碼會顯示"你不能管理這個使用者"，
> 還有在選擇編輯生字的時候，如果沒有打開管理頁面不會自動打開，所以請調整這個，最後在錄音的介面有點擠迫，可以大一點」

### 1. 連上網（Supabase adapter ＋ Vercel 專案）

`lib/store/supabase.js` 完成，`DATA_BACKEND=supabase` 就會切過去；本機 Demo 仍是 JSON。

**為什麼寫成「每個請求先抓下來、回應前寫回去」**：這個專案的路由是同步風格（上百處 `store.xxx()` 直接取值），
全部改成非同步要動到所有路由；而且 serverless 在回應送出後會**凍結實例**，
「回應之後再慢慢寫」等於準備掉資料。所以：

1. `/api/*` 進來先 `hydrate()`：把 7 張表抓進記憶體（連最大 id，用來本地配 id）。
2. 路由照舊同步讀寫（新增的列由本地配 id —— schema 用 `generated by default as identity`，可以把 id 一起 INSERT，
   所以 Postgres 配的 id 跟回給前端的 id 一致）。
3. 回應送出**之前** `flush()`：按外鍵順序寫回（刪除：子表先；新增：books → units → entries → …）。
   **寫回失敗回 500，不假裝成功**；失敗的那批異動會丟掉並強制下次重新 hydrate，
   不讓記憶體留著「其實沒寫進資料庫」的假資料。

已實測（打真的 Supabase 專案，跑完自己清乾淨）：
`node scripts/supabase-smoke.js --write` → 寫入書本／單元／生字／帳號／授權／稽核 → **用全新連線讀回**
（id 一致、密碼雜湊驗證通過）→ 刪除 → 確認 7 張表回到 0 筆。

Vercel 專案 `pv-dictionary` 已建立並連結 GitHub（push `main` 自動部署）：
https://pv-dictionary-mylearning.vercel.app —— 只差兩個環境變數（見下）。

### 2. 修改自己的密碼

- 標題列多一個 🔑：任何登入的人（老師、科代表、管理員）都能改**自己的**密碼，要輸入目前的密碼
  （`POST /api/auth/change-password`）。成功的、失敗的都會明確提示（目前的密碼錯 → 「目前的密碼不正確」）。
- **修好你回報的 bug**：在帳號管理面板替「自己」重設密碼原本會回 403「你不能管理這個使用者」——
  現在自己可以改自己的密碼與顯示名稱，但**不能改自己的角色、不能停用自己**（那是提權與自鎖）。
- 改密碼會留稽核紀錄（`PASSWORD_CHANGE`）。

### 3. 按「編輯生字」會自動打開管理區

以前的流程是「先按 ✏️ 管理，再按生字卡上的編輯」；沒開管理區就按編輯，表單雖然打開了卻在畫面外，
看起來像沒反應。現在 `ensureAdminOpen()` 會**自動打開管理區、切到那張表單、並捲到它**。
（批次貼上同理。）

### 4. 錄音介面加大

面板從 26rem 加到 36rem、按鈕改成兩欄網格並放大到 50px 高（窄螢幕自動變一欄）、
狀態訊息自己一行。驗收會實際量：寬度 ≥500px、按鈕高 ≥44px。

### 你要做的一件事（部署才會通）

Vercel → `pv-dictionary` → Settings → Environment Variables，把這兩個的 `REPLACE_ME…` 換成 `.env` 裡的真值：

| 名稱 | 值從哪裡來 |
|---|---|
| `JWT_SECRET` | `.env` 的 `JWT_SECRET`（或 `openssl rand -hex 32` 產生一組新的） |
| `SUPABASE_SERVICE_ROLE_KEY` | `.env` 的 `SUPABASE_SERVICE_ROLE_KEY`（Supabase → Settings → API → service_role） |

填好後按 Redeploy。**這兩個值是機密，請直接從 `.env` 複製到 Vercel 介面，不要貼在對話或文件裡。**
（`DATA_BACKEND`／`SUPABASE_URL`／`SITE_URL` 我已經設好了。）
程式有守門：看到 `REPLACE_ME` 會**當場拒絕啟動**（回 500），不會用猜得到的密鑰跑起來讓你以為好了。

## PV_Dictionary v0.0.1（Demo）

給英文老師與學生使用的線上生字字典：學生點書本 → 點單元 → 看生字表 → 點 🔊 聽讀音。
**這個版本是 Demo，跑在本機**（資料存在 `data/store.json`，尚未接 Supabase）。

### 這一版有什麼

- **瀏覽**：書本 / 單元切換、生字卡（生字、美式／英式 IPA、詞性、中文解釋、英文解釋、中英例句）、即時搜尋。
- **讀音**：有老師錄音就播錄音（顯示 👩‍🏫 徽章），沒有就用瀏覽器語音合成；同一顆 🔊。
- **管理（老師以上）**：新增／修改／刪除生字、批次貼上匯入、新增單元與書本、上傳或直接用麥克風錄老師錄音、稽核紀錄。
- **審核流程**：科代表新增 → 「待審核」（學生看不到）→ 老師核准 → 學生才看得到。
- **權限階梯**：訪客／學生（免登入）< 科代表 < 老師 < 網頁管理員 < 網站擁有者；另有單元級授權的 API。
- **列印**：單元頁可列印成生字表。
- **安全**：JWT 放 HttpOnly cookie、CSRF 來源檢查、登入鎖定（單 IP 10 次／15 分鐘）、嚴格 CSP（無 `unsafe-inline`）、
  所有寫入動作寫稽核、音檔走自家同源端點（同源與大小上限都驗過）。

### 測試結果（實跑）

| 項目 | 指令 | 結果 |
|---|---|---|
| 語法 + 模組載入 | `npm run check:syntax` | 22/22 通過 |
| 單元／API 測試 | `npm test` | **35 通過 / 0 失敗** |
| 真實瀏覽器驗收 | `npm run check:browser` | **39 通過 / 0 失敗** |

瀏覽器驗收走完 12 步 Demo 劇本：訪客瀏覽與 TTS 播放 → 搜尋 → 管理員新增／批次匯入／刪除（兩段式確認）
→ 老師錄音上傳與播放來源切換 → 新增單元與書本 → 科代表待審核 → 老師核准 → 訪客可見；
另含 402px 手機不溢出、無 CSP 違規、無前端例外、**不寫任何截圖**、**不觸發任何下載**。

### 怎麼跑

```bash
npm install
npm run seed      # 示範課本 2 本 × 3 單元 × 6 生字，帳號密碼只寫進 .env
node server.js    # http://localhost:3000
grep SEED_ .env   # 看帳號密碼（manager / owner / teacher / classrep）
```

### 已知限制

- **JSON 資料層不能上 Vercel**（serverless 沒有持久磁碟）；線上版要等 v0.1.0 的 Supabase adapter
  （schema 已在 `migrations/2026-10-08-v0.0.1-init.sql`）。
- TTS 聲音取決於裝置與瀏覽器，不是字典的標準發音；iOS 需在手勢中播放。
- 單筆錄音上限 1MB／60 秒。

# v0.13.0 — 列印學習單加強（B-9）＋ 學生端小功能（F-5）

- 發佈日期：2026-10-11
- 線上：https://gary-dictionary.vercel.app
- 上一版：v0.12.0（B-8 刪除年級／單元、D-9 每季追蹤、發版前檢查）

## 這一版做了什麼

### B-9 列印學習單（老師）

| 新選項 | 行為 |
|---|---|
| 中文留白 | 中文解釋的位置留一條線讓學生填（文字透明、**不佔位**） |
| 字母順序 | 照 a→z 排（不分大小寫），不照單元順序 |
| 列印整個單元 | 按 🖨 時若還有沒載入的生字，**會先把整個單元抓完再印**（上限 1000 筆；超過會提示學習單可能不完整） |

- 為什麼「整個單元」要另外處理：生字表是分頁的（D-11，一頁 60 筆），
  以前只印畫面上那幾頁，老師要出學習單就會缺字。
- 技術細節：留白用 `color: transparent` ＋ 下框線，**不是** `display: none`
  —— 這樣列高不變、每一列的間距才會一致。兩個選項各自存在 localStorage
  （`pd.printBlankZh`／`pd.printAlpha`），下次回來還在。

### F-5 學生端小功能

- **★ 我的清單**：每一列生字最前面多一顆 ☆，點一下收藏（★ 代表已收藏）。
  按工具列的「我的清單」就只看**這個單元**收藏的字，按鈕上會顯示收藏數。
  刻意只存在**自己的瀏覽器**（localStorage，不用帳號）—— 換手機或清掉瀏覽器資料就不會跟著走，
  站內說明有寫清楚，不让人以為「登入別的裝置也看得到」。
- **只看沒有中文解釋的字**：老師／科代表補中文時用；勾了只顯示缺中文的生字。
- **兩個篩選都在資料庫端做**（`?ids=…`、`?missing_zh=1`），不是在前端過濾已載入的那一頁
  —— 否則「明明有 5 個沒中文，卻只找到 2 個」。
  帶了不合法的 `ids`（例如 `?ids=abc`）會回**空清單**，不會退化成「整個單元」。

### 資料庫與資料

- 「沒有中文解釋」統一用 **NULL** 表示（空字串一律正規化），
  見 `migrations/neon/2026-10-11-null-empty-meanings.sql`（已套用；實際 0 筆需要轉換）。
  - 為什麼：PostgREST **不接受** `or=(zh_meaning.is.null,zh_meaning.eq.)`（`or=` 裡出現空字串條件會直接 400，已實測），
    只有 NULL 能用單一條件 `zh_meaning=is.null` 過濾，而且能和搜尋的 `or=` 用 AND 疊起來。
  - 讀取端完全不受影響：`publicEntry()` 一律回 `''`，前端拿到的東西跟以前一樣。
- 寫入端（`applyEntryInput`）同步改成把空的中文解釋存成 NULL。

### 站內使用說明

說明頁多了兩節（中英都有）：「老師：列印學習單」與「學生：我的清單」。

### 驗收過程中自己踩到、自己修掉的

1. **☆ 按鈕只有 17px 高** → 手機守門測試（「高度 < 28px 的按鈕數＝0」）抓到 6 顆；
   修法：`.star-btn` 給 `min-height: 1.9rem` ＋ inline-flex 置中（點擊面積本來也該夠大）。
2. **手機工具列被壓成細條** → 控制項從 4 個變 6 個，`.unit-head-actions` 沒換行；
   修法：`flex-wrap: wrap`、按鈕 `flex: 0 0 auto` ＋ `min-height: 2rem`，勾選項自己佔一行。
3. **我自己寫的瀏覽器守門一開始讀不到值** → `browser.evaluate()` 是把字串當**函式主體**，
   一定要 `return (() => {…})();`，不能只寫 IIFE。
4. **CSS 用了不存在的變數** → `--muted-foreground`／`--background` 在 tokens.css 裡叫
   `--text-muted`／`--bg`（v0.12.0 的刪除確認列也踩到同一個坑，一併修掉）。

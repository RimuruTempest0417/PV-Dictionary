## PV_Dictionary v0.4.4 — 稽核匯出與統計，外加你指定的三件事

這一版原本排的是 A-3（稽核匯出與保留期清理）與 B-7（使用統計），另外加上使用者指定的三項：
密碼訊息修正、擴充功能造成的 CSP 噪音處理、以及「所有帳號所有裝置一起登出」按鈕。

### 1. 修復：「密碼長度必須是 –64 個字元」（`{min}` 沒有值）

英文訊息是對的（`The password must be 10–64 characters long`），但**中文的 `{min}` 沒有值**：
後端只把 `{min}` 插進英文訊息（`msg()`），而前端是用回應的 `details` 當插值變數
（`i18n.js` 的 `errorMessage` → `t(code, error.details)`）—— `details` 是空的，
所以佔位符被拿掉，變成「必須是 –64 個字元」。
現在三個入口（建立帳號／管理員改密碼／自己改密碼）都回 `details: { min: 10 }`，
`tests/api.test.js` 也加了斷言，之後不會再退回去。

### 2. 擴充功能造成的 CSP 違規：可以忽略（而且現在不會再回報）

**可以忽略，而且我用證據確認過**：我用一個乾淨、沒有任何擴充功能的瀏覽器載入正式站 → 0 筆違規；
違規只在「有擴充功能的瀏覽器」出現（Google 翻譯、深色模式、閱讀模式都會往頁面注入行內樣式）。

因此這一版做了兩件事：

- **前端不再回報這類噪音**：`public/js/errorlog.js` 遇到 `style-src-elem`／`style-src-attr`
  且被擋的是 `inline` 就跳過。可以安全忽略的理由寫在程式碼裡：我們的 CSP 沒有 `unsafe-inline`，
  而且 `tests/guards.test.js` 會擋掉任何行內 `style` 與 `style` 屬性 ——
  所以這種違規不可能來自本專案的程式碼；真的自己寫了行內樣式時，守門測試會先紅燈。
- **已經進來的同類紀錄可以一鍵清掉**：錯誤紀錄每一列多一顆
  **「同類全部標為已處理」**（同 code + message 一次處理完），會留一筆稽核 `ERROR_LOG_RESOLVE_SIMILAR`。

### 3. 帳號管理：「所有帳號、所有裝置一起登出」（只有 web_manager）

放在「➕ 新增帳號」旁邊（使用者指定位置），**只有網站管理員看得到**（admin 按下去會回 403）。
按一次進入確認狀態、按第二次才真的執行；執行後**包括自己這一台在內的所有帳號、所有裝置都會登出**
（實作是把每個使用者的 `token_version` +1，舊權杖立即全部失效），畫面立刻回到未登入狀態。
稽核會留一筆 `ALL_USERS_FORCE_LOGOUT`。

### 4. A-3 稽核匯出與保留期清理

- **CSV 匯出**：「🧾 稽核紀錄」面板多一顆「⬇ 匯出 CSV」，吃跟列表一樣的篩選條件。
  兩個容易忽略但一定要做的細節：
  - **加 UTF-8 BOM**：不加的話 Excel 開中文會變亂碼（實測匯出檔的前 3 個位元組是 `EF BB BF`）。
  - **公式注入防護**：值以 `= + - @` 開頭時前面補一個單引號（稽核紀錄裡有使用者輸入的帳號與生字，
    否則 Excel 會把它當公式執行）。實測 `=SUM(A1:A9)` 匯出後變成 `'=SUM(A1:A9)`。
- **保留期清理**：「🧹 清理舊紀錄」第一次按只**預覽**（不會刪），第二次才真的刪；
  天數下限 30 天、預設保留 365 天；清理本身也留一筆稽核 `AUDIT_CLEANUP`。
  資料層也補了 `deleteAuditLog()`（JSON 與 Supabase 兩邊都有）。

### 5. B-7 使用統計

管理選單多一頁「📊 概況」：教材數字（已確認／待審核生字、書本、單元、空單元）、
錄音覆蓋（幾個已發佈生字還沒有老師錄音）、帳號（啟用數、角色分佈、開了兩步驟驗證的人數）、
授權數、最近 7 天的動作統計，以及各單元生字數。**只回聚合數字，不含任何個資**（測試有斷言）。
